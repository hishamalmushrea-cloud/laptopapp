# العمل من الهاتف / Phone workflow

> مكتوب لمن يعمل من هاتف بلا كمبيوتر. لا تحتاج Android Studio، ولا JDK، ولا أي أدوات بناء.

## القاعدة الأهم

**لا تضف ملفات يدويًا إلى المشروع.** أي ملف تحتاجه — كود، تعديل، إعداد، توثيق —
أنا أكتبه وأدفعه إلى الفرع. دورك ثلاثة أشياء فقط:

1. **تصف** ما تريده (بالعربي، وبأي صيغة، حتى بصوت مُحوَّل إلى نص).
2. **تجرّب** على جهازك وتخبرني بالنتيجة.
3. **تقرّر** بين الخيارات when أعرضها عليك.

كل ما أدفعه يظهر لك فورًا على:
`https://github.com/hishamalmushrea-cloud/laptopapp/tree/arena/01a08d26-laptopapp`

## المسارات الثلاثة المتاحة لك من الهاتف

### (أ) تعديل المشروع عبري — متاح الآن، لا يحتاج شيئًا

اكتب لي مثلًا:
- «غيّر اسم التطبيق إلى X»
- «أضف لغة عربية للقوائم»
- «خلّي الإعداد الافتراضي Turnip بدل Vortek»
- «اشرح لي ماذا يفعل ملف ContainerManager.java»

أنا أعدّل وأتحقق وأدفع، وأعطيك رقم الكوميت.

### (ب) تجربة التطبيق على جهازك — متاح الآن

لتجربة فعلية، نزّل **Winlator الرسمي** (ليس من مستودعنا — مستودعنا لم يُبنَ بعد):

- الإصدار المستقر: `Winlator_11.1.apk` — **149.7 MB** (‏156,943,882 بايت)
- من: `https://github.com/brunodev85/winlator/releases`
- شروط جهازك (من `app/app/build.gradle`): **Android 8.0 أو أحدث** (`minSdk 26`)
  و**معالج arm64-v8a** فقط.

ثم جرّب لعبة/برنامجًا وأخبرني: هل فتح؟ ما سرعة الإطارات؟ أي أخطاء ظهرت؟
هذه المعلومات تساوي ذهبًا للمشروع — راجع البند (ج) أدناه.

### (ج) بناء نسختنا أنت — يحتاج تفعيل CI مرة واحدة فقط

**لا يمكن بناء التطبيق على الهاتف.** المشروع يحتاج NDK ‏24.0.8215888 + CMake + SDK 35،
وهذا غير عملي حتى عبر Termux (بناء NDK بهذا الحجم سيستهلك هاتفك).

الحل: **البناء السحابي عبر GitHub Actions**. عند تفعيله:
- كل push → يُبنى APK في سحابة GitHub مجانًا.
- تنزّل الـ APK من صفحة Actions على هاتفك مباشرة.
- **لا تحتاج كمبيوتر إطلاقًا، ولا مرة.**

الملف جاهز عندنا في `ci/build.yml` (وظيفتان: تحقق البصمات ثم بناء APK مع `SHA256SUMS.txt`).

## كيف تفعّل CI من الهاتف

### الطريقة 1 (الأسهل): أعطِ الصلاحية ثم أخبرني

GitHub رفض دفعتي لأن التوكن الآلي لا يملك صلاحية `workflows`. الرسالة الحرفية:

```
remote: refusing to allow a GitHub App to create or update workflow
        `.github/workflows/build.yml` without `workflows` permission
```

الخطوات من متصفح هاتفك:

1. افتح `https://github.com/hishamalmushrea-cloud/laptopapp/settings/installations`
2. اختر تطبيق **Arena** ثم **Configure**
3. انزل إلى **Repository permissions**
4. **Workflows** ← غيّر من `No access` إلى **Read and write**
5. **Save**
6. اكتب لي هنا: «فعّلت الصلاحية» — وأنا أدفع الملف وأراقب أول بناء

### الطريقة 2: أنشئ الملف بنفسك من موقع GitHub

1. افتح المستودع على فرع `arena/01a08d26-laptopapp`
2. **Add file** ← **Create new file**
3. في خانة الاسم اكتب بالضبط: `.github/workflows/build.yml`
   (كتابة `/` تنشئ المجلدات تلقائيًا)
4. انسخ محتوى `ci/build.yml` والصقه
5. **Commit changes**

## معلومات أحتاجها منك (مهمة جدًا لهذا المشروع بالذات)

المشروع كله يدور حول نوع الكرت الرسومي — Vortek وTurnip وGladio لكل منها مسار مختلف:

| المعلومة | لماذا |
|---|---|
| موديل الهاتف + نسخة أندرويد | `minSdk 26`، و`targetSdk 28` |
| نوع المعالج/الكرت (Adreno / Mali / Xclipse) | `GraphicsDrivers.getDefaultDriver()` يختار `turnip` فقط إذا `getAdrenoModelId() > 0` |
| حجم الذاكرة (RAM) | الحاوية تحتاج ذاكرة كبيرة |
| هل جربت Winlator من قبل؟ وماذا حدث؟ | يحدد أول شيء نصلحه |

## تنبيهات عملية

- **البيانات:** الأصول الثنائية **480 MB** والـ APK النهائي ~**150 MB**. استخدم واي فاي.
  (هذه التنزيلات تحدث عندي أو في CI — لا على هاتفك، إلا الـ APK النهائي إن أردت تجربته.)
- **الفرع:** كل عملي على `arena/01a08d26-laptopapp`. لا تعمل على `main` مباشرة.
- **لا تحذف `.gitkeep`** في `wine_addons/` و`graphics_driver/` و`soundfont/` و`jniLibs/arm64-v8a/` —
  هي التي تُبقي المجلدات موجودة في git بينما محتواها يُجلب بالسكربت.
- **إن أردت نسخة خاصة على GitHub باسمك:** ادخل على `brunodev85/winlator` واضغط **Fork**.
  أنا لا أستطيع إنشاء مستودعات جديدة — التوكن هنا مثبَّت على `laptopapp` فقط
  (تحقّقت: `gh api user` يعيد `403`، وقائمة المستودعات المتاحة تحتوي `laptopapp` وحده).
